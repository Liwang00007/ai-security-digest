# AI 安全情报

面向个人使用的公开信息 AI 安全日报与周报。完整稿保存在这个公开 GitHub 仓库，飞书接收摘要；日报仍处于试运行阶段，周报已安排每周一汇总上周。

## 收录原则

- 优先使用监管机构、厂商、GitHub Advisory、研究机构等一手公开来源。
- 每条均区分“事实”“判断”和“建议动作”，并保留原始链接与发布日期。
- 自动整理不等于事实已核验；未能交叉验证的内容会明确标为“待核验”。
- 不保存客户资料、个人资料、账号凭据或受版权保护文章全文。

## 目录

```text
reports/
├─ daily/     每日情报
└─ weekly/    每周复盘
```

首期为试运行样刊，采用近 7 天公开资料加一条仍需优先处理的高风险组件通告；后续稳定后才会切换到严格的 24 小时窗口与飞书推送。

## 使用边界

本仓库内容是公开信息的摘要与分析，不构成安全、法律、投资或采购建议。使用前请回到原始来源，并按实际环境完成验证。
