# 科技与产业情报

面向个人使用的公开信息日报与周报，覆盖互联网、金融与金融科技、科技、AI 和机器人。完整稿保存在这个公开 GitHub 仓库，飞书接收摘要；周报已安排每周一汇总上周。

## 收录原则

- 优先使用监管机构、厂商、GitHub Advisory、研究机构等一手公开来源。
- 每条均区分“事实”“判断”和“建议动作”，并保留原始链接与发布日期。
- 自动整理不等于事实已核验；未能交叉验证的内容会明确标为“待核验”。
- 不保存客户资料、个人资料、账号凭据或受版权保护文章全文。
- 不强求每周每个赛道都有事件；没有足够一手证据时明确标注覆盖缺口，不为凑分类填充内容。

## 目录

```text
reports/
├─ daily/     每日情报与专题日报
└─ weekly/    科技与产业周报
```

首期专题日报采用近 7 天公开资料建立基线，并非严格的 24 小时扫描。后续周报按上一完整自然周汇总，并以全球公开一手来源为主。
